# מנווט יתר לחץ דם: אפליקציה לטלפון (PWA)

## מה יש כאן

- `index.html`: המחשבון. הקוד שלך לא השתנה, רק נוספה לו שכבת אפליקציה.
- `sw.js`: שומר את המחשבון במכשיר, כדי שיעבוד בלי אינטרנט.
- `manifest.webmanifest`: השם, הצבעים והאייקון של האפליקציה.
- קבצי `png` ו-`svg`: האייקונים.

כל הקבצים יושבים באותה תיקייה, בלי תת-תיקיות, כך שאפשר להעלות את כולם בבת אחת, גם מהטלפון.

## שלב 1: לשים את הקבצים ברשת (פעם אחת, בחינם)

אפליקציה כזו צריכה כתובת https. הדרך הפשוטה היא GitHub Pages.

1. מחלצים את ה-ZIP. באנדרואיד: פותחים את אפליקציית הקבצים, לוחצים על ה-ZIP ובוחרים **חילוץ**.
2. נכנסים ל-github.com בדפדפן ונרשמים (בחינם).
3. לוחצים **New repository**. נותנים שם, למשל `htn`, מסמנים **Public**, ולוחצים **Create repository**.
4. בעמוד שנפתח לוחצים **uploading an existing file** (או **Add file**, ואז **Upload files**). בוחרים את כל הקבצים שחולצו ולוחצים **Commit changes**.
5. נכנסים ל-**Settings**, ואז **Pages**. תחת **Build and deployment** בוחרים ב-**Source** את **Deploy from a branch**. ב-**Branch** בוחרים `main` ואת `/(root)`, ולוחצים **Save**.
6. אחרי דקה או שתיים הכתובת מופיעה באותו עמוד. היא נראית כך: `https://שם-המשתמש.github.io/htn/`

שימו לב: במנוי החינמי המאגר והאתר ציבוריים. אין בזה בעיה, כי בקוד אין פרטי מטופלים.

## שלב 2: להתקין בטלפון

- **אנדרואיד (Chrome):** פותחים את הכתובת ולוחצים על **התקנה** בפס הירוק שמעל הלשוניות. האפשרות נמצאת גם בתפריט **שיתוף**, תחת **התקנה כאפליקציה בטלפון**. אם אין אף אחד מהם, פותחים את התפריט ⋮ של Chrome ובוחרים **התקנת אפליקציה** או **הוספה למסך הבית**. אחרי ההתקנה המחשבון מופיע במגירת האפליקציות ובהגדרות של אנדרואיד, כמו כל אפליקציה.
- **אייפון (Safari):** פותחים את הכתובת ולוחצים על **התקנה** (בפס הירוק, או בתפריט **שיתוף**), ויופיעו ההוראות. בקצרה: כפתור השיתוף (ב-iOS 26 הוא בתוך התפריט ⋯), אחר כך **הוספה למסך הבית**, משאירים את **Open as Web App** דלוק, ולוחצים **הוסף**.

אחרי פתיחה ראשונה עם אינטרנט, המחשבון עובד גם בלי חיבור.

## לשתף עמיתים

שולחים להם את הכתובת ולא את הקובץ, וכל אחד מתקין לעצמו.

## לעדכן גרסה

1. בונים מחדש את הקבצים מהקובץ המעודכן. אפשר לבקש את זה מ-Claude.
2. ב-GitHub: **Add file**, אחר כך **Upload files**. מעלים את כל הקבצים החדשים (הם דורסים את הישנים) ולוחצים **Commit changes**.
3. בפתיחה הבאה, מי שהתקין יקבל הודעה "יש גרסה חדשה" עם כפתור **רענון**.

חשוב: מעלים את `index.html` מהחבילה החדשה. לקובץ המקורי אין שכבת אפליקציה.
